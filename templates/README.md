# Page scaffolds (optional, project-specific)

Drop known-good page exports here — a validated drawer form, an IR list page,
an IG tab, an audit tab — with page numbers as `PNN` placeholders. New pages
start as a copy of a scaffold instead of being grepped together from scratch;
one contributor reported this saving most of a day on the first module.

These are inherently project-specific (they carry your templates and auth
schemes), so the starter ships this folder empty: populate it from your own
app's first few validated pages.
